# Palorant

**Palorant** is a fan-made web project inspired by *Valorant*, built entirely using **pure HTML, CSS, and JavaScript**. This project focuses on delivering a clean, interactive, and visually engaging experience without relying on external frameworks or libraries.

---

## 🚀 Features

* ⚡ Fully responsive UI design
* 🎨 Clean and modern layout inspired by Valorant
* 🧭 Smooth navigation and user interaction
* 🖼️ Custom styling and animations using pure CSS
* 🧠 Vanilla JavaScript for dynamic behavior

---

## 🛠️ Tech Stack

* **HTML5** – Structure and layout
* **CSS3** – Styling, animations, responsiveness
* **JavaScript (Vanilla)** – Interactivity and logic

---

## 💡 Purpose

This project was built to:

## 🖥️ Getting Started

To run the project locally:

1. Clone the repository:

   ```
   git clone https://github.com/your-username/palorant.git
   ```

2. Navigate into the project folder:

   ```
   cd palorant
   ```

3. Open `index.html` in your browser.
